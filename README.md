# Copilotu Sonsuz Bekletme Makinesi

## Projenin Resmi Amacı

Bu proje, GitHub Copilot'un önerilerini alırken yaşanan o eşsiz bekleyiş hissini bilimsel olarak simüle etmek için tasarlanmıştır. 

**Uyari:** Bu yazılım gerçekten yavaştır. Gerçekten bekletir. Gerçekten hiçbir işe yaramaz. Ama çok ciddidir.

## Nasıl Çalışır?

1. Programı çalıştırırsın.
2. Bir soru sorarsın (veya sormazsın, fark etmez).
3. Copilot "düşünür".
4. Sonsuza yakın bir süre bekler.
5. Sonunda saçma bir cevap verir.
6. Tekrar başa döner.

Bu döngü, evrenin ısı ölümüne kadar devam eder (veya sen Ctrl+C yapana kadar).

## Bilimsel Temel

Araştırmalar (kaynak: ben) göstermiştir ki, Copilot'un yanıt süresi ile kullanıcının sabır seviyesi arasında ters orantı vardır. Bu proje bu orantıyı maksimize eder.

## Kurulum

```bash
pip install time
python copilot_bekletici.py
```

(Evet, `time` modülü zaten Python ile gelir. Ama ciddiye almak için yazdık.)

## Lisans
